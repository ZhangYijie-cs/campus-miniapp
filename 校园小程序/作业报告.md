# 食光探店 · 作业报告

## 一、项目简介
「食光探店」是基于微信原生小程序的美食发现与评价应用，使用 WXML、WXSS、JavaScript 开发。提供 12 家本地模拟店铺，覆盖火锅、奶茶、烧烤、面食、小吃五类。所有业务在本地运行，无需后端、云环境、登录或网络图片配置。

视觉采用橙色 #FF6B35、暖黄与奶白背景；白色卡片采用 16rpx 圆角和轻投影，星星为 #FFB800，价格为红色。图片采用本地保存的真实美食照片，按店铺类型搭配封面与三张轮播图；图片仅作美食示意，不代表模拟店铺的实际菜品。底部导航图标为本地绘制 PNG，无图标库依赖。

## 四、核心实现思路
### 1. 数据和缓存
使用 `shiguang-food-v1` 作为存储键，仅保存 `{ favorites, reviews }`。读取时校验数据类型、店铺 ID 和星级范围；展示层由原始店铺与用户数据动态合成，不改动种子数据。同步写入成功后才更新页面，保存失败会提示，防止错误显示已成功。清除微信小程序数据会清空个人记录；不同设备不互通。

### 2. 评分计算与页面联动
每家店铺的初始评价和本机新增评价一起计算：`平均分 = 所有评分之和 / 评价总数`。内部保留完整数值用于榜单排序，展示时保留一位小数。星星使用四舍五入后的整数颗数，精确分值通过数字展示。榜单同分时依次按评价数、ID 排序，保证稳定性。各页面在 onShow 中重新读取，发布评价返回详情、切换首页或榜单时自动刷新。

### 3. 搜索与收藏
搜索框 bindinput 实时匹配店名和分类，同时与选中的分类取交集。收藏 ID 数组写入本地缓存，卡片爱心使用 catchtap，避免收藏操作触发详情跳转。收藏页只展示收藏中的店铺，取消后即时移除。

### 4. 评价提交
星级必须是 1～5 的整数，昵称不能为空且最多 16 字，内容去除首尾空白后不能为空且最多 300 字。提交时生成唯一 ID、实际时间与 mine 标记。提交期间锁定按钮避免重复提交。成功后返回详情；独立打开评价页没有上级页面时回退到对应详情。

### 5. 适配与离线资源
宽度采用 rpx、百分比及 flex，横向分类支持滚动，长店名省略、长评价可折行。底部操作栏为 iPhone 安全区预留空间。所有实拍照片均打包到本地，断网仍能展示，页面明确说明店铺为模拟数据。

## 五、运行方法
1. 使用微信开发者工具导入本项目根目录，工具按 project.config.json 使用 miniprogram/ 作为小程序目录。
2. 当前保留原项目 AppID；若无对应权限，请在开发者工具中改为自己的 AppID，或使用测试号进行本地学习调试。
3. 普通编译，启动页选择 pages/index/index。无需安装 npm 包，无需开通或部署云开发。
4. 在首页搜索或切换分类，点击卡片；选择「写评价」填写后提交，再查看详情、首页、榜单与我的页面。
5. 收藏店铺后进入收藏页；关闭并重新打开小程序检查记录是否保留。
6. 分享需使用微信提供的右上角分享菜单；真实分享需在具备相应权限的微信环境中验证。
